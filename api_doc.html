3. Detailed API Specifications

API 1: Submit Account Deletion Request

Endpoint: POST /api/user-account/delete

Headers: Authorization: Bearer <JWT_TOKEN>, Content-Type: application/json

Request Body Parameters:

Field Type Required Description
id String Yes User ID (MongoDB ObjectId) ya 10-digit Phone Number.
duration Integer Yes Kitne din baad delete karna hai. Agar 0 hai to turant delete hoga.
reason String No Account delete karne ka reason.
deviceType String Yes Device platform: "android", "ios", ya "web" allow hai.

Sample Request (Scheduled Deletion - e.g. 5 Days):

{
  "id": "9876543210",
  "duration": 5,
  "reason": "I no longer want to use the application",
  "deviceType": "android"
}

Success Response (200 OK):

{
  "success": true,
  "message": "Account deletion scheduled successfully",
  "deletionRequestData": {
    "deleteStatus": true,
    "deleteRequestDate": "10/09/2026",
    "deleteRequestProcessDate": "15/09/2026",
    "deleteRequestProcessDays": 5
  }
}

Immediate Deletion Request (duration = 0):

{
  "id": "9876543210",
  "duration": 0,
  "reason": "Deleting immediately",
  "deviceType": "ios"
}

Immediate Deletion Response (200 OK):

{
  "success": true,
  "message": "Account has been deleted immediately"
}

API 2: Cancel Account Deletion Request

Endpoint: POST /api/user-account/cancel-delete

Headers: Authorization: Bearer <JWT_TOKEN>

Request Body: None (User identity JWT Token se automatically extract hoti hai).

Success Response (200 OK):

{
  "success": true,
  "message": "Account deletion request cancelled successfully",
  "deletionRequestData": {
    "deleteStatus": false,
    "deleteRequestDate": null,
    "deleteRequestProcessDate": null,
    "deleteRequestProcessDays": 0
  }
}

5. Step-by-Step Postman Testing Guide

Note: Test karte waqt ensure karein ki aapka backend server chal raha ho (e.g. npm run dev ya node server.js) aur MongoDB connected ho. Default port 3000 hai.

Step 1: Bearer Token Hasil Karein (Login)

  1. Postman me new request create karein: POST
  2. URL: http://localhost:3000/api/auth/verify-login-otp
  3. Body > raw > JSON: 
    {"phoneNumber": "9876543210", "otp": "1234"}
  4. Response me se token string ko copy kar lein.

Step 2: Submit Delete Request Test Karein

  1. Method: POST
  2. URL: http://localhost:3000/api/user-account/delete
  3. Headers tab me add karein:
    • Authorization : Bearer <Step 1 me mila token>
    • Content-Type : application/json
  4. Body tab > raw > JSON: 
    {
  "id": "9876543210",
  "duration": 5,
  "reason": "Temporary break",
  "deviceType": "android"
}
  5. Send click karein. Aapko 200 OK aur updated deletionRequestData milega.

Step 3: Login Response me Verification

  1. Wapas Step 1 wali login request send karein.
  2. Check karein ki user ke profile me account_status: "PENDING_DELETION" aur deletionRequestData.deleteStatus: true aa raha hai.

Step 4: Cancel Deletion Request Test Karein

  1. Method: POST
  2. URL: http://localhost:3000/api/user-account/cancel-delete
  3. Headers tab: Authorization: Bearer <Token>
  4. Body: Empty rakhein.
  5. Send click karein. 200 OK response aayega aur deleteStatus: false ho jayega.
Validation & Error Scenarios to Test:
  • Missing deviceType: Agar body me deviceType na ho, API 400 Bad Request return karegi.
  • Invalid duration: Duration negative ya non-number hone par 400 Bad Request aayega.
  • Duplicate Cancel: Agar deletion request already cancel ho chuki ho to API 400 Bad Request ("No active deletion request found") degi.
